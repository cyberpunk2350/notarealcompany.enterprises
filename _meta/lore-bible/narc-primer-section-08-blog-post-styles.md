## 7. Blog Post Styles

See Section 06 (§5.11) for the full style overview including file prefixes and the Hybrid memo header template.

**Blog section path:**[^1] `blogs/` from the site root. All relative paths in existing blog posts (ADR links, internal references, seal image paths) should be calculated from this directory depth. Final path and structure to be confirmed and implemented in BR-004.

**Neutral** — Appropriate when the content should reach a general technical audience or when NARC framing would distract. No organizational headers. Section headings as H2. References block at end. Occasional dry observation is fine; none is required.

**NARC v2** — For lore-leaning posts if that content type develops. Classification header (no TO/FROM), ITCRuD footer, references block. Calibrated against existing site document tone. Uses the terminology and framing of the lore bible without saturating.[^1]

**Hybrid** — Primary production style.[^1] Official memo header, then first-person technical narrative. Creates genuine utility in NARC framing, accessible to a general internet reader. Suits posts documenting real work done inside the fictional organization. See Section 06 (§5.11) for the full header template.

**NARC v1** — Archived.[^1] Three posts exist as a record of the experiment. Ran too hot; hard to follow for a general reader. No new v1 content to be commissioned.
