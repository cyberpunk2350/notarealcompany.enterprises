## What This Is

The NARC Lore Bible is the canonical reference document set for the NARC project — a mock-corporate homelab environment at [notarealcompany.enterprises](https://notarealcompany.enterprises). It defines the characters, tone, terminology, document conventions, and visual standards that make NARC content consistent across all sessions, branches, and contributors.

If you are producing content for NARC — documents, blog posts, project cards, meeting minutes, or anything else — start here.

## The Short Version

NARC is a mock-corporate homelab. Real infrastructure; fictional corporate framing. The humor lives in the gap between the seriousness of the writing and the obviously fictional subject matter. Documents never wink at the camera.

**The cast:**

| Name | Title | The one thing to remember |
|------|-------|--------------------------|
| Jane Doe | CEO | Virtualizes everything |
| John Smith | CFO | Notices costs. Don't overplay it. |
| Mary Johnson | CTO | Fond of blinking status lights |
| Robert Lee | COO | Runs IT Operations |
| Linda Park | HR Director | Enforces morale |
| Max Pitchman | Head of Marketing | Used-car salesman energy; ends up in every meeting |
| Dr. Sylvia Sparks | Head of R&D | "For science." |
| Alex Firewall | CISO | Files formal objections. Has opinions. They are on file. |
| Chuck Cheerful | Happiness Officer | "Happiness is Mandatory." |
| Victor Watchful | Head of Internal Security | Always informed as a precaution. Always. |
| `[REDACTED]` | IT Director, ITCRuD | Name withheld. Do not invent one. |
| ARIA v2.1 | Meeting minutes | Clinical. Her appendix is honest. |
| NARC-Brew 3000 | Coffee | Fleet. Everywhere. Nobody reads its advisories. |
| `[REDACTED]` | The Founder | Ultraviolet clearance. Probably exists. No one has seen them. |

**The Computer** is omnipresent. It appears through seals and approval blocks. No employee names it directly. Its power comes from the silence around it.

**Clearance levels:** Infrared (lowest) → Red → Orange → Yellow → Green → Blue → Indigo → Violet. Ultraviolet is reserved for the Founder.

**Key terminology:**
- Employees (not Citizens)
- Termination Event (not Treason Event)
- Corporate drones (not clones)
