## How to Use This Document Set

The lore bible is divided into numbered sections and appendices. Sections 01–09 are the canonical reference — read these to produce correct NARC content. Sections 11–12 are project and artifact tracking. The appendices are reference, historical record, and maintenance guides.

**Cold session minimum read:** Sections 01, 02, 03. Everything else is reference.
