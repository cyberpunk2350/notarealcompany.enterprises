# AI Media MCP Servers

**Department:** R&D  
**Category:** Prototype  
**Status:** Active  
**Clearance:** Orange and Above  

## Description
A suite of AI-integrated media management servers enabling Authorized Personnel to delegate the entire physical media lifecycle to their AI overlord of choice. Covers metadata retrieval, disc ripping, transcoding, and container manipulation — because manually typing a filename is a waste of Complexity Points that could be spent on Mandatory Fun Activities.

## Features
- Automatically retrieves metadata from three separate approved databases, then argues with itself about which one is correct.
- Rips physical media into formats the Computer has pre-approved. Unapproved formats are logged for review.
- Transcodes video to target quality levels. Quality targets above Clearance Orange require additional sign-off.
- Strips, remuxes, and tags media containers. Audio tracks in languages not on the Approved Language Registry will be quietly removed for your convenience.
- All file path access restricted to Authorized Directories. Attempts to access Unauthorized Directories are a Treason Event.

## Notes
- Citizens must supply their own API keys. Loss of API keys is a demerit. Loss of API keys three times is a different kind of demerit.
- MakeMKV requires a valid license. Beta licenses are acceptable. Expired licenses are a known issue. This is Fine.
- Disc drive must be physically present. The Computer does not yet support holographic media. This is on the roadmap.
- Jellyfin and SFTP integrations are Planned Features. Asking when they will be ready is not recommended.
