# NARC New Associate Onboarding Packet

Welcome to **Not A Real Company (NARC)**.

This onboarding packet provides new associates with essential information about organizational structure, operational expectations, and corporate culture.

---

# 1. Welcome to NARC

NARC is committed to maintaining a highly professional corporate environment designed to support infrastructure experimentation and operational excellence.

All associates contribute to maintaining the illusion of a fully operational enterprise organization.

---

# 2. Corporate Principles

All associates are expected to support the following values:

- Operational Excellence
- Infrastructure Reliability
- Procedural Compliance
- Strategic Over-Engineering

---

# 3. Organizational Structure

NARC is divided into four primary divisions:

| Division | Function |
|--------|---------|
| NOPS | Operations |
| NIS | Infrastructure Services |
| NSEC | Security Division |
| NRD | Research Division |

Ultimate authority rests with **The Computer**.

---

# 4. Documentation Standards

All documentation must follow established naming conventions and templates. Full standards are in `Corp-Standard-Internal-DocumentationStandards.md`.

Example naming scheme:

```
Department-Type-Audience-Title.md
```

---

# 5. Communication Standards

Associates should maintain a professional tone in all communications.

Example closing statement:

> Deployment has been approved by The Computer.

---

# 6. Required Accounts

New associates must be provisioned with:

- Infrastructure login
- Documentation repository access
- Monitoring dashboard access
- VPN access

Refer to `IT-Procedure-Internal-VPNSetupGuide.md` for VPN setup.

---

# 7. Security Responsibilities

All associates must comply with NARC security standards, including Password Rotation, System Hardening, and Access Control policies.

---

# 8. Final Statement

Welcome to NARC. Your cooperation ensures continued operational success and procedural authenticity.
