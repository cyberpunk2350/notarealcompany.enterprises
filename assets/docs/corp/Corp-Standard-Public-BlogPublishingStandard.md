# NARC Blog Publishing Standard

Organization: Not A Real Company  
Website: https://notarealcompany.enterprises

---

## Purpose

This document defines the structure and publishing standards for blog posts published on the NARC website. The goal is to maintain a consistent tone, structure, and formatting across all public-facing content.

---

# 1. Blog Objectives

Blog posts should:

- Document NARC projects
- Explain technical experiments
- Share infrastructure insights
- Present humorous corporate commentary

Posts should maintain the **tongue-in-cheek corporate tone** that reflects the fictional nature of NARC.

---

# 2. Blog Categories

| Category | Description |
|------|------|
| Infrastructure | Homelab infrastructure |
| DevOps | Automation and tooling |
| Security | Security practices |
| R&D | Experimental work |
| Operations | Operational lessons |
| Corporate Satire | Humor about fake corporate processes |

---

# 3. Writing Style

Tone should be technical, slightly corporate, lightly humorous, and informative.

Example:

> "In keeping with NARC's commitment to operational excellence, we deployed a completely unnecessary monitoring stack for a server that hosts exactly three containers."

---

# 4. Recommended Length

| Type | Word Count |
|------|------|
| Announcement | 300–500 |
| Technical walkthrough | 800–1500 |
| Deep dive | 1500+ |

---

# 5. Structure

Standard sections:

1. Introduction
2. Problem Statement
3. Solution / Implementation
4. Lessons Learned
5. Future Work

---

# 6. Images and Diagrams

Images stored in `blogs/[project-id]/images/`. Preferred formats: SVG for diagrams, PNG for screenshots.

---

# 7. Tags

Recommended tagging:

```
homelab
infrastructure
networking
automation
security
narc-infrastructure
```

---

# 8. Publishing Workflow

```
Draft → Internal Review → Publish
```

---

# 9. Attribution

Posts should include an author signature:

```
— NARC Infrastructure Team
```

---

# 10. Legal Disclaimer

All blog posts should include a footer disclaimer:

> NARC (Not A Real Company) is a fictional organization created for homelab experimentation and documentation. Any resemblance to real corporate bureaucracy is purely intentional.
